## Decisions and assumptions
- **DEC-020** (appended to `docs/delivery/decisions.md`): `next_opening` returns a window start only where the service was closed the instant before. This reads the prompt's "when a window starts" so that adjacent windows and an every-day all-day service do not report false openings. It is an interpretation, and the verifier should check it against the prompt.
- `SEARCH_DAYS = 8` is named as [ASSUMED] from the prompt's "next 8 days" rule.
- Property tests exclude window bounds in the 01:00 to 02:00 hour on the change dates, because the oracle reads the local wall clock there. Instants in that hour are still tested.
