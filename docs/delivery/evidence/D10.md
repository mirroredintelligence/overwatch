## Decisions and assumptions
- **DEC-010 stub** in the red commit: `SERVICE_LETTERS` only (a constant, no behaviour).
- **Changed D09 property test** (`test_parser_never_raises_and_only_returns_in_range_figures`): it asserted `len(replies) == 1` for every text. That invariant is wrong once a lettered reply returns several items. The test now checks each item, requires a single item only for `Unrecognised`, and checks that letters are in `SERVICE_LETTERS` and not repeated. This edits an existing D09 test and is recorded here rather than hidden. A decision entry is added to `decisions.md` (DEC-022).
- **Routing**: a message takes the lettered path only when one of its tokens is a service letter, a letter with figure (`A4`) or `Y` with a letter (`YA`). D09-valid replies contain none of these, so D09 behaviour cannot change. Non-ASCII is still refused before upper-casing, so dotless `ı` cannot become `I`.
- **Commas** separate items only. `A,4` (no space) is refused, because the item boundary is the comma and an item needs a letter and a figure inside it.
- `[ASSUMED]` values used: letters A to H (at most 8 services); figures 0 to 999 (`MAX_FIGURE_DIGITS`).
