## Privacy
Scan of the diff `main..HEAD` (backend and docs/delivery) for the three shapes. Every hit is a synthetic probe or a spec sample:
- Postcode shapes: `DT4 8XX` (the spec's sample, also in domain-rules and the standard), `DT48XX`, `dt48xx`, `dt4 8xx`, `QZ9 9ZZ` (invented, not a real postcode).
- NHS-number shapes: `943 476 5919`, `9434765919`, `943-476-5919`, `943 476-5919`. These are the sample the D17 prompt gives. It is the number NHS documentation uses as an example. It is not checked against the NHS record system, and it is used only as a string that the guard must flag.
- Titled names: `Mrs Smith`, `Dr Jones`, `Dr. Jones`, `Miss Jones`, `Mr. Brown`. All invented and used as probes.
- No real patient, name, NHS number or postcode appears in a fixture, template or log.

**Shapes the scan covers (exactly):**
1. Full UK postcode, one or two letters, a digit, an optional letter or digit, a digit, two letters. Case-insensitive, word-bounded, any whitespace or none between the halves (DEC-043 item 1).
2. NHS-number shape: 10 contiguous digits, or 3-3-4 with a space or hyphen at each join (the two joins may differ), not part of a longer digit run (DEC-043 item 2).
3. Personal title Mr, Mrs, Ms, Miss or Dr, in any case, with an optional full stop, then whitespace, then a capitalised word (DEC-043 item 3).
4. Forbidden call-level field names: name, patient_name, nhs_number, postcode, address, dob, date_of_birth, free_text (refused by `render`).

**Shapes the scan does not cover:** a bare two-word name with no title (for example `Jane Smith`), since a general name rule would flag place names such as `UCR West`; NHS-number shapes split by letters or other punctuation; free text in any field, including the K3 `body` (DEC-037 item 7); and the id fields (DEC-041 item 8). The sweep sees only synthetic samples, so a free-text value supplied by a caller is not checked here. This is the lesson of D25 in practice: the probe test covers name-shaped values only in the forms the guard recognises.

## Decisions and assumptions
- **DEC-043** (published, `docs/delivery/decisions.md`): postcode whitespace and case, NHS separators, title case and whitespace, output order, the newline join of text/subject/html, the probe test scope, forbidden-field handling, what the guard does not cover, and the build-failure mechanism.
- Lesson: none published by this build. Prompt test 7 and the forbidden-field refusals passed on the red commit, because D15's `render` already refuses unknown fields. This is recorded in DEC-043 item 7.
- Assumption: `Dr` in the title list means the medical title, as the prompt states; `Ms` is in the list as the prompt states.
