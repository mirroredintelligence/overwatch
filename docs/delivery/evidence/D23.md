## Decisions and assumptions
- **DEC-036** (new, on this branch) records the choices the prompt leaves open:
  - A lapsed lock refuses advice (`NotAllowed`), and the taker must take the request again.
  - Re-taking a live lock by the same clinician keeps the original `taken_at`.
  - Only `Presence` members are counted.
  - `advice_shown_as_available` fails closed.
  - Constructors validate urgency, the taken fields and timezone-awareness.
  - `release_for_away` returns only the released copies.
- **Contract addition:** `advice_shown_as_available(available: int | None, queue_known: bool) -> bool` is added to `docs/spec/contracts.md` (the line for `rules/clinical_queue.py`).
- **Prompt rule not changed, but flagged:** `queue_order` keeps the prompt's signature, which has no `now`. It leaves out a request that is still locked even when the lock is idle. U40 must call `return_if_idle` before `queue_order`. This is DEC-036 item 7.
- **Clock:** the module reads no clock and does no London-time conversion, so lessons L4 and L25 do not apply to it. Every instant is timezone-aware and is compared in UTC.
- **Enum pattern:** `Presence` is matched by `isinstance` and identity, following lessons L3 and L38.
- No `[ASSUMED]` constants are used: `TAKE_TIMEOUT` and `NOTE_MAX` are the values in the prompt and the rule book.
