# Evidence: D23 Clinical advice queue and presence rules

Builder: build-D23 · Branch: `task/D23-clinical-queue` · Prompt: `docs/plan/prompts/D23.md`

## Summary
The domain rules for the clinical advice queue exist in `backend/src/diucs/domain/rules/clinical_queue.py`. Taking locks a request. A lock is idle after 10 real minutes, with instants compared in UTC so the London clock changes are handled. Only the taker can give advice, and only once. Going away releases unadvised requests. Presence counts only available advisors. `advice_shown_as_available` returns a real `bool`, True only when the count is above zero and the queue is known. Nothing calls these rules yet; the use case and timers are U40.
