- Assumed: default `size` is `sm` (the prompt does not give a default). `sm` is min-height 2rem, `lg` is min-height `--chip-h` (48px).

- `tokens.css` declares no colour on `html` or `body`, so the board's colours are not forced globally. Only the font rule is on `html`. Dark mode is out of scope.
- Test-order deviation, stated because the red commit does not hold them: the layout font test was written after the red commit and was seen failing (`expected "vi.fn()" to be called with arguments`) before `layout.tsx` was changed. The `sets the page font` test in `tokens.test.ts` was added after `tokens.css` had the `html` rule, and was not seen failing first (the verifier's mutation of the html rule showed it fails). The red commit's axe test was changed before red was committed, so it fails on the missing badges rather than passing against an empty stub.
- The contrast ratio is calculated for six-digit hex only. Anything else is not supported and is not tested. The CSS-derived pair test throws on any colour it cannot resolve to six-digit hex.
