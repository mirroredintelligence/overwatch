## Decisions and assumptions
- **DEC-013** (new, in `docs/delivery/decisions.md`): the harness starts its own container every session, sets `NEO4J_URI`/`NEO4J_USER`/`NEO4J_PASSWORD` for that session, ignores a `NEO4J_URI` already in the environment, and wipes only through `harness_driver`. It clarifies DEC-008 and the F10 prompt, which disagree on whether an unset `NEO4J_URI` fails the session. I followed the prompt's "the harness sets the URI itself".
- **Deviation, container timing:** the prompt's "5 seconds, else fail with the start message" applies to `connect_or_fail`. Starting the container takes longer, so readiness is polled for up to 120 s (`CONTAINER_READY_TIMEOUT_S`).
- **Deviation, failure message:** when Docker cannot start the container, the message says Docker could not start the Neo4j test container. It does not use the docker-compose start message, because that message points at the shared stack. The exact start message is still raised by `connect_or_fail`.
- **Deviation, no testcontainers:** the container is started with the `docker` CLI through `subprocess`, which the prompt allows. No dependency was added, so `uv.lock` is unchanged.
- **Edit to G01's file:** `backend/tests/integration/graph_store/test_driver.py` had a module-scoped `neo4j_driver` fixture that read `NEO4J_URI` and failed when it was unset. G01's own docstring said the F10 harness would supply the URI. I removed that fixture, so the tests use the session driver, and changed `loop_scope="module"` to `"session"`. The tests are otherwise unchanged.
- **Fixture naming:** the session driver is `harness_driver`. `neo4j_driver` is a thin session fixture that returns it, so a test module can override the name. `test_infra_up.py` (F04) does this and keeps its own driver on the compose stack. `clean_graph` depends on `harness_driver`, so it never wipes whatever `neo4j_driver` resolves to in a module.
- **Loop scopes:** `asyncio_default_fixture_loop_scope` and `asyncio_default_test_loop_scope` are `"session"` in `backend/pyproject.toml` (pytest-asyncio 1.4.0 option names). `pythonpath = ["."]` was added so tests import `tests.support`.
- **Clean-up scope:** `clean_graph` keeps `:Migration` nodes and deletes everything else in batches of 10,000, as the prompt says. Constraints and indexes are not touched by deletion.
- **Not added:** `uow_factory` (P06), repositories, Redis and Service Bus fixtures are out of scope and were not built.
