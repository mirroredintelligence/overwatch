# Evidence: I01 Redis cache adapter

Builder: build-I01 · Branch: `task/I01-redis-cache` · Prompt: `docs/plan/prompts/I01.md`

## Summary
`RedisCache` implements the `Cache` port on Redis: text values with a TTL, publish and subscribe for `board.updates`, and single-flight locks with fencing tokens. It passes the same 23 cache contract cases as the in-memory fake, against the Redis of `infra/docker-compose.yml`. Before this task the cache had only the in-memory fake and no Redis adapter.
