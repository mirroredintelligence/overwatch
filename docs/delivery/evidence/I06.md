## Summary
The Twilio SMS adapter now sends texts through an injected `httpx.AsyncClient`, maps Twilio status callbacks to `DeliveryUpdate`, separates accepted, refused, transient and failed sends, and adds the Twilio settings. Before this branch none of that existed.
