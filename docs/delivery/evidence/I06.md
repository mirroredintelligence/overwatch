# Evidence: I06 Twilio SMS adapter

Builder: build-I06 · Branch: `task/I06-twilio-sms` · Prompt: `docs/plan/prompts/I06.md` · Decisions: DEC-103

## Summary
`TwilioSms` implements `SmsSender` over the Twilio Messages API with an injected `httpx.AsyncClient` and no SDK. It sends a text, maps the provider's answer to a `SendReceipt` or to the port's errors, normalises UK mobile numbers to E.164, and maps Twilio status callbacks to `queued | sent | delivered | failed`.

**No live Twilio call was made.** Every test goes through an `httpx.MockTransport`. No real credential, account SID, token or number was used. The live path is human-only.

## Privacy
Diff scan for UK postcode, NHS-number and titled-name shapes: only the sample number `07700 900123` (Ofcom drama range) and its E.164 form, in tests and docstrings, and the placeholder SID `AC` plus 32 zeros. No real number, name or postcode. The adapter logs message id, Twilio sid, status and provider error code only. Tests read the log and assert that the number, E.164 form, body, token and account SID are absent at INFO and above.
