## Summary
`SmtpEmail` sends the capacity and booking emails through an SMTP relay as `multipart/alternative` (text first, HTML second), with `Auto-Submitted: auto-generated`, a generated `Message-ID`, and a role-inbox recipient. A 4xx answer or a lost connection is transient, a 5xx recipient refusal is `accepted=False`, and nothing logs an address, a body or an exception's text. No real mail was sent: every test runs against an in-process aiosmtpd server on 127.0.0.1.
