# Evidence: I09 Email adapter (SMTP) with HTML and text bodies

Builder: build-I09 · Branch: `task/I09-email-smtp` · Prompt: `docs/plan/prompts/I09.md`

## Summary
`SmtpEmail` sends the capacity and booking emails through an SMTP relay as `multipart/alternative` (text first, HTML second), with `Auto-Submitted: auto-generated`, a generated `Message-ID`, and a role-inbox recipient. A 4xx answer or a lost connection is transient, a 5xx recipient refusal is `accepted=False`, and the adapter's logs carry no address, body or server reply text on the success, refusal, deferral or failure paths. No real mail was sent: every test runs against an in-process aiosmtpd server on 127.0.0.1. The D15 email footer is missing one screen sentence, so the footer criterion is partial (see Requirement trace).
