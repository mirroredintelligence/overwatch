## Decisions and assumptions
Full list in `docs/delivery/decisions.md`, **DEC-063**. In brief:
- businessStatus and reference are properties written after the store's put (DEC-063 items 1 and 2). The status is not stored as a relationship, so there is one copy.
- Task.restriction and Task.output are backbone elements, added as two entries in the mapper's `_BACKBONE` table (DEC-063 item 3). This is a change to `adapters/outbound/graph_store/mapper.py`, which is not in this task's listed files; it is two lines and the mapper's full unit suite still passes. The reply-by time is the child property `periodEnd`, not the Task property `restrictionPeriodEnd` the spec table names.
- confirmed_at is kept in a `confirmed-at` output entry, not a property (item 5).
- Output type codes use a new local system `CodeSystem/booking-output-type`, not yet in contracts.md (item 4).
- A racing-add test was added beyond the prompt's list, following lesson L73.
