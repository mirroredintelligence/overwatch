The three mutated files were compared with their saved copies after every mutant: all clean.

Why M8 is equivalent. The invariant is: the `CURRENT_CRITERIA` link of a service points only at its current version. Two facts keep it. First, `_finish` runs after every write, and for any version that is not current it runs `Q-CRIT-CLEAR-CURRENT`, which removes the link to that version. Second, `_check_slot` allows at most one current version per service, and the service lock serialises the writes. So when a version becomes current, every earlier link has already been removed by the write that made its version non-current, and no stored state holds a second link. The `DELETE old` in `Q-CRIT-SET-CURRENT` therefore deletes nothing that the invariant allows to exist. It is not a missing guard.

A first attempt at M8 dropped `s` from scope along with `old`. The query then failed (13 failed). That run tests a Cypher error, not the guard, and is discarded.
