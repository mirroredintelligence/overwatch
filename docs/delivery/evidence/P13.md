# Evidence: P13 Registration and scope list ports with Neo4j repositories

Builder: build-P13 · Branch: `task/P13-registration-scope-list` · Prompt: `docs/plan/prompts/P13.md`

## Summary
The registration (Task `register-service`) and scope-list (one `List`, `ENTRY` relationships) records now have ports and Neo4j repositories. Registrations round-trip through the graph with a typed draft, and the scope list creates a minimal inactive service for an entry before it registers. Both writes are guarded: a draft is replaced as a whole, a second save for a service that is being created waits for the first and succeeds, and invalid values are refused before any write.
