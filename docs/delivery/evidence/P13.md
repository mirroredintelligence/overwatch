Guards: the draft is replaced as a whole; a second save for a service being created waits and succeeds; a text date and a stored instant are refused; invalid values are refused before any write. - DEC-082: the scope list is `(:Resource:List {id: 'scope-list'})`; ENTRY facts are relationship properties; a minimal service is created before it registers; the write lock is taken first; entries sort by name, then service id.
