## Summary
Command results can be stored under a command key and replayed with no second effect, and a
consumer can mark a message handled once per consumer. Both are Neo4j-backed, join the unit of work
(`uow.idempotency`, `uow.processed`), and are guarded by unique keys, raw-constraint tests and
held-transaction race tests. The result is stored as typed nodes, not JSON text (DEC-090 item 1).
