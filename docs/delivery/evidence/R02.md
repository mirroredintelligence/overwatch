# Evidence: R02 Authentication, roles and service scope

Builder: build-R02 · Branch: `task/R02-auth-roles` · Prompt: `docs/plan/prompts/R02.md`

## Summary
Every FHIR call is now checked against a bearer token from the BFF (HS256, stdlib codec in the domain). A valid token gives an `Actor`. The helpers `require_role`, `ensure_can_act_for` and `ensure_patient_access` refuse with the same 404 body as a missing record. A projection registry removes the case and patient references from a reporter's Task and labels the result REDACTED. Before this change the FHIR app had no authentication.
