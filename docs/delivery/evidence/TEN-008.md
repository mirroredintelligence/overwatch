## Summary
The mapper now refuses a resource that carries the names the tenancy seam owns, `tenantId` and `sourceTenantId`, at any depth and in any shape, refuses an extension registered under either name, refuses any fragment that would put one on a node or relationship, and drops both from every node it rebuilds a resource from. A resource therefore cannot forge, move or overwrite the tenant stamp the writer adds (TEN-009), and a stamped node does not turn the stamp into a FHIR element on read. The mapper stays pure; the writer stamps Concept, CodeSystem and Identifier like every other node (DEC-162).
