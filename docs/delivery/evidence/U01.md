# Evidence: U01 ReportCapacity use case

Builder: build-U01 · Branch: `task/U01-report-capacity` · Prompt: `docs/plan/prompts/U01.md`

## Summary
`ReportCapacity` records a capacity figure for a service. It checks the figure and the actor, stores the report, computes the status before and after (with the suspended flag and confirmed bookings), and writes the report, the `CapacityReported` and `StatusChanged` outbox messages, the C3 or C4 echo, the audit entry and the idempotency result in one unit of work. A repeated command key replays the first result without writing again.
