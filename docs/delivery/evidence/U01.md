## Decisions and assumptions
- **DEC-106** (new): a stored key is decided before the other checks and again inside the unit of work. Amends DEC-104 item 4, whose in-unit-of-work check was not in the code at `5a66ca5`.
- **Open for the owner, not decided by the builder**: `_echo_text` formats `next_prompt`, which `next_due` returns as `None` when no due time falls in its search window. The C3 template needs `next_due`. At runtime `format_hhmm(None)` raises, so the report transaction rolls back. The right behaviour (skip the echo, send a different echo, or accept the report without one) is a product decision. This path has no test. mypy strict flags it.
- **DEC-100 item 2 not implemented**: `replaced_value` outside 0 to 999 should raise `ValidationFailed("replaced_value")`. The use case does not check it, and no test covers it.
