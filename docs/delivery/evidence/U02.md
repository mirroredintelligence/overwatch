## Summary
A reporter or advisor can confirm the latest figure ("Y"). It is stored as a `confirmed` report derived from the latest report, counted against the two-in-a-row limit, audited as `ConfirmCapacity`, and answered with the C3 echo for a text source. The unit of work takes the service's write lock first (P04 pattern), so two simultaneous confirmations cannot both read a count of 1 and write a third. Every item of the verifier's first-round fail (verify-U02, seven findings) is addressed; see the table below.
