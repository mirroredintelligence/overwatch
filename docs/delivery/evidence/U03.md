# Evidence: U03 SendPrompts use case (one service)

Builder: build-U03 · Branch: `task/U03-send-prompts` · Prompt: `docs/plan/prompts/U03.md`

## Summary
`SendPrompts` sends C1 or C2 to each textable reporter role and records the communication, the link token (hash only), the ladder, the next prompt and the audit entry in one unit of work. The outbox holds the content sealed, so no token text is at rest. Every skip still re-arms the next prompt. `schedule_work` and `cancel_work` are the shared helpers. This is round 2, after verify-U03 failed round 1 (findings A to K, DEC-115 items 10 to 21).
