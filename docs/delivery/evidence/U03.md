# Evidence: U03 SendPrompts use case (one service)

Builder: build-U03 · Branch: `task/U03-send-prompts` · Prompt: `docs/plan/prompts/U03.md`

## Summary
`SendPrompts` sends C1 or C2 to each textable reporter role, and records the communication, the link token (hash only), the ladder, the next prompt and the audit entry in one unit of work. The outbox holds the content sealed with AES-256-GCM, bound to the outbox message id, the tenant and the recipient role. Every skip re-arms the next prompt. A nobody-to-text prompt starts a service-level ladder. `schedule_work` and `cancel_work` are the shared helpers. This is round 3, after verify-U03-r2 failed round 2 (findings 1 to 6, DEC-115 items 22 to 29, DEC-116).
