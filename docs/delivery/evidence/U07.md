# Evidence: U07 Raise report flags when reports break rules

Builder: build-U07 · Branch: `task/U07-report-flags` · Prompt: `docs/plan/prompts/U07.md`

## Summary
A capacity report that breaks a flag rule is now stored with its flag: `record_report` calls the new `raise_report_flags` in the same unit of work, for numbers (`ReportCapacity`) and confirmations (`ConfirmCapacity`) alike. Each flag is an open `ReportFlag` on the report, announced by a `ReportFlagged` outbox message and named in the audit entry. `ReportCapacity` no longer refuses a flag, so U05's out-of-range-twice figure is stored with its flag and the fallback in `HandleInboundText` is gone. A Y no longer confirms the old figure while an out-of-range figure is waiting to be sent again (DEC-161 item 9).
