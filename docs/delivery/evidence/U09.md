# Evidence: U09 Board projector: cache and live updates

Builder: build-U09 · Branch: `task/U09-board-projector` · Prompt: `docs/plan/prompts/U09.md`

## Summary
The board projector now rebuilds the wall board from Neo4j when a board-relevant event arrives, stores it under `board:v1` with a 60 s backstop, and publishes a `board-changed` message on `board.updates` that carries no figures. `get_board` serves the cached board, recomputes when the cache is empty, expired or unreadable, and never raises because of the cache. Nothing of this existed before U09.
