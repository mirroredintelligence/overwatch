## Summary
A wall display can now start a pairing (a six-digit code and a secret it alone holds), a shift lead can confirm the code with a screen name, and the display can collect a 128-bit device token once. Everything is tenant-bound (from the unit of work only), rate limited, single use and refused with one identical error for every wrong, expired, used or other-tenant code or secret. The device is stored in Neo4j as a tenant-stamped `:Device` node holding only the token hash.
