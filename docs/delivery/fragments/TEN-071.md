# TEN-071: network directory and criteria views

Bundle WB10. Tests: `components/network/{NetworkServicesView,NetworkServiceDetail}.test.tsx`, `components/scope/NetworkServiceCard.test.tsx`, `lib/network/hours.test.ts`, `app/(network)/network/pages.test.tsx`, `test/guards/network-views.test.tsx`.

## Decisions

### DEC-1198 The directory and the service detail are read only, current version only (TEN-071; docs/design/network-ui.md section 4; audit D Q9, Q10, Q11)
Status: accepted (bundle WB10, under DEC-133). Affects: `components/network/{NetworkServicesView,NetworkServiceDetail}.tsx`, `components/scope/NetworkServiceCard.tsx`, `lib/network/hours.ts`, `app/(network)/network/services/`.
1. **The list** (`/network/services`) is the directory in the back end's order, with the count line, the read-only note, an organisation filter and a category filter (both in place, over the rows the page has). A service its organisation set inactive (`active: false`) is not listed. A row's one control is its name, a link to `/network/services/{rowRef}`: the reference is the opaque one the back end gave the row. A paused listing says "Not available on the network. Phone to confirm."
2. **The detail** reads the directory and the criteria and finds the row by reference. Sections: About this service (whose, what and where, where the entry came from), Opening hours (`hoursText`: "Mon to Fri 08:00 to 20:00", "Every day, all day", "Opening hours not shared"), Service line (the number as a link to phone, or "No number shared") and Criteria. A reference that is not there, is malformed, or a refused read is the one "Network view not available" panel.
3. **Criteria are the current version only**: Accepts, Does not accept (the need labels), Ages, Districts, Review by; no reason, owner, version or history, and no way to report a problem (that message would go to an organisation the viewer cannot message). A service with none says "No criteria shared"; a criteria read that fails says "The criteria could not be read. Phone to confirm." and keeps the rest of the page.
4. History is the history page's (TEN-070), not a view here.

## Hazards

H-N02's part for these views (a member sees another member's private data): the list and detail show only the fields of the back end's allow-listed projection, rebuilt by the parser; no comment, reporter, booking or case field exists in them; checked by `network-views.test.tsx` and the parser tests. No new hazard.
