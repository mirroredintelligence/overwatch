# W12 fragment: referrer score pickers

## Decision

DEC-635 A referrer's score is written to the ServiceRequest as one complex extension per score (`SCORE_EXTENSION`, `https://diucs.example/StructureDefinition/score`) with a `method` (valueCode) and a `value` (valueInteger for NEWS2, Frailty scale and ambulance category; valueString for the Manchester word and the Pathways Dx code). The shape is proposed here for the back end to adopt: the back end does not read it yet (H-323).
1. Each method at most once. A NEWS2 score is a whole number from 0 to 20; a Frailty scale value is 1 to 9; an ambulance category is 1 to 4; a Manchester word is one of the five; a Pathways code is letters, digits, dot, dash or underscore, up to 32 characters.
2. The browser offers only codes from the lookup for Pathways. The BFF checks the shape only; it cannot check that a code is in the list, since the list is the back end's.

DEC-646 The Pathways Dx lookup is advisor-only (the prompt). The case routes admit advisor and lead (DEC-632). The back end's terminology route admits advisor and clinical (R16). A lead therefore sees the case but not the lookup.

## Contracts

- Components: `ScorePickers` (props `value: Score[]`, `onChange(scores)`), with sub-components `News2Picker`, `CfsPicker`, `PathwaysPicker` in the same file.
- Lib: `lib/advisor/scores.ts` (`Score`, `AcuityMethod`, `ACUITY_METHODS`, `MANCHESTER_TRIAGE`, `AMBULANCE_CATEGORIES`, `CFS_LABELS`, `NEWS2_MAX`, `CFS_MIN`, `CFS_MAX`, `PATHWAYS_MIN_CHARACTERS`, `PATHWAYS_DEBOUNCE_MS` (250), `PATHWAYS_RESULTS_MAX` (20), `PATHWAYS_CODE`, `parseNews2`, `parseScores`), `lib/advisor/terminology.ts` (`searchPathwaysDx`, `PathwaysDx`).
- BFF: `GET /api/bff/terminology/pathways-dx?q=` (advisor only; `q` trimmed, 2 to 64 characters, else 400) answers `[{ code, display }]`, at most 20.
- Back-end call: `GET /terminology/pathways-dx?q=` at the back end's root (not under `/fhir`). `lib/fhir/client.ts` gained the optional `root` flag for this (additive).
- Score extension: `SCORE_EXTENSION` in `lib/advisor/case-fhir.ts`.
