# W16 fragment: no service fits state

## Decision

DEC-642 "Widen the time" is offered only when the case is within 2 hrs. It saves the whole case, as the needs form does, with urgency `today`, using the ETag it read as If-Match, then reads the options again. A case that is not within 2 hrs is never widened by this button.

The state follows DEC-643 (W13): it always offers a next step and never ends the call. The primary action is last in the DOM, so it is the bottom action on the phone layout; "Back to needs" is the secondary link above the options.

## Hazards

None new. The widen change is a save of the same case; the risk it carries is the urgency change itself, which is the advisor's decision and is recorded as the case's urgency.
