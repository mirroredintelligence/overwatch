## Decision
Offline shell and installable app (W32)
1. The service worker's logic lives in `frontend/public/sw-logic.js` (a classic script, exposed as `self.DiucsSw`) and `public/sw.js` loads it with `importScripts`. The tests load the same shipped file, so the tested logic is the logic that ships.
2. The offline page holds no tenant, service or capacity data. Its text says "phone the SPOA on the number your service has on record", because the SPOA number is per organisation and the precached shell must not hold organisation data (DEC-134 item 3, DEC-660 item 3). The number is shown from the API where a page has one.
3. Only `/offline` and `/_next/static/*` (GET) are cached. Navigations that fail offline get the offline page. `/api/bff/*` and every other HTML page are never cached.
4. Manifest icons are plain generated placeholder PNGs (`public/icons/*.png`), to be replaced by the design asset.

## Hazards
| id | hazard | source | control | tasks | verified by | status |
|---|---|---|---|---|---|---|
| H-335 | A cached page or BFF response shows capacity or a service after the reporter is signed out, or to the next user of the phone | service worker caching | only `/offline` and static assets are cached; `isCacheable` refuses everything else (unit-tested) | W32, W35, W37 | test/pwa/sw-logic.test.ts | controlled in unit tests; e2e not run |

## Known issues
| W32 | notification click on a closed-tab client opens `/app` only when the url is off-origin; no e2e check of focus on iOS | public/sw.js | iOS standalone focus behaviour is untested here | needs a real iPhone check at deploy |

## Contracts
- `public/manifest.webmanifest`, `public/sw.js`, `public/sw-logic.js` (`DiucsSw.handlePush`, `pickClientOrOpen`, `isCacheable`).
- `app/offline/page.tsx` (`OfflinePage`), `components/pwa/RegisterServiceWorker.tsx` (`RegisterServiceWorker`).
- `app/layout.tsx`: manifest metadata, `viewport.themeColor`, registration component in body.

## Tenant pending
None: the worker and shell hold no tenant data.

- Icons are placeholder PNGs (solid #0B5C8C with a light disc).

- Playwright and Lighthouse: not run here (orchestrator runs e2e). Installability in Chrome: not checked by hand in this sandbox.
