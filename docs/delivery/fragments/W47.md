# W47 fragment: lead audit replay screen (what the advisor saw) and export

## Decision

DEC-656 (W47) · The replay shows an integrity warning when the back end's `chain_ok` is false: "This replay did not pass its integrity check. Do not rely on it until it is checked." The prompt does not give this case. A replay whose chain does not verify is shown with that warning, never without it, because the lead would otherwise read a broken record as a sound one. The wording is for the owner and information governance to confirm.

DEC-653 (W47, see W18) · The export is a plain GET (a link with `download`), so it needs no CSRF token, and it is read-only. The CSV has one table: the services shown, then the timeline. Fields that start with a formula character (= + - @) are given an apostrophe so a spreadsheet does not run them; this is an addition to the prompt's escaping rule.

DEC-657 (W47, see W42) · The replay's `decisionAt` is the back end's `shown_at`. "Criteria version N" is shown once when every service has the same version, and per service otherwise.

H-333 (W47) · Both the page's read and the export are `no-store` at the BFF and on the back-end call (`fhirFetch` with `root: true` and `cache: 'no-store'`). A refusal and an unknown reference give the same 404 and the same words, so the page does not reveal which.
