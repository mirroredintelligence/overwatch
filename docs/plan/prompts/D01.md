**Goal.** Model a service's reporting profile as validated value objects. Every capacity rule reads from this profile.

**Read first.**
- `backend/src/diucs/domain/codes.py` (F07): `Measure`, `Cadence`, `Channel`, `ServiceCategory`.
- `backend/src/diucs/domain/errors.py` (F01): `ValidationFailed`.
- `docs/spec/domain-rules.md`, section 1.1.

**Rules you need.**
- Profile fields (set at registration): `measure` (free-slots, free-beds, referrals-acceptable, occupied-patients, packages-free); `unit_label` ("referrals in the next 2 hrs"); `established_capacity` (normal maximum, e.g. 8); `can_exceed_established` (virtual wards and hospital at home can run over); `usual_range` (range check, e.g. 0 to 8); `cadence` (every-2-hrs, twice-a-day, once-a-day); `limited_level_percent` default 80 [ASSUMED]; `available_times` (London local days and hours the service accepts referrals; may be all day); `channel` (text, email, push).
- Days are integers 0 = Monday … 6 = Sunday.
- An available time either is all day (no start or end) or has a start and an end. An end earlier than the start means the window runs past midnight (an overnight service 20:00–08:00). The end is exclusive.

**Build.** `backend/src/diucs/domain/model/service.py`:
- `AvailableTime(days: frozenset[int], all_day: bool, start: time | None, end: time | None)` with `__post_init__` validation.
- `ServiceProfile(id: str, name: str, category: ServiceCategory, measure: Measure, unit_label: str, established_capacity: int, can_exceed_established: bool, usual_range: tuple[int, int], cadence: Cadence, available_times: tuple[AvailableTime, ...], channel: Channel, limited_level_percent: int = 80, active: bool = True, suspended: bool = False, comment: str = "")` with validation.
- Helpers (extra public names): `AvailableTime.weekdays(start: time, end: time)` for Mon–Fri, `AvailableTime.every_day(start: time, end: time)`, and `AvailableTime.every_day_all_day()`.
- Every failure raises `ValidationFailed(field, message)` naming the field.
