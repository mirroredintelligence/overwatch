**Goal.** Model a capacity report and pick the latest one. Reports are immutable measurements: a correction is a new report, never an edit.

**Read first.**
- `backend/src/diucs/domain/model/service.py` (D01).
- `backend/src/diucs/domain/codes.py` (F07): `Measure`, `ReportSource`, `ReportType`.
- `docs/spec/fhir-data-model.md`, "Capacity report (Observation)".

**Rules you need.**
- A report has a whole-number value, the measure, when it applies (`effective_at`), its source (text, link, app, email, advisor-phoned, feed) and its type: `number` (a figure was sent) or `confirmed` (a "Y" confirming the previous figure; it points at the report it confirms through `derived_from`).
- "We are closed to referrals" is a report with `value=0`.
- The latest report is the one with the greatest `effective_at`.

**Build.** `backend/src/diucs/domain/model/capacity.py`:
- `CapacityReport(id: str, service_id: str, value: int, measure: Measure, effective_at: datetime, source: ReportSource, report_type: ReportType, performer_role_id: str | None = None, derived_from: str | None = None)`.
- Validation in `__post_init__`: value ≥ 0 (`ValidationFailed("value", ...)`); `effective_at` timezone-aware (`ValidationFailed("effective_at", ...)`); `report_type == CONFIRMED` requires `derived_from` (`ValidationFailed("derived_from", ...)`).
- Property `is_closed -> bool` (extra public name): `value == 0` and the measure is not `OCCUPIED_PATIENTS`.
- `latest_report(reports: Iterable[CapacityReport]) -> CapacityReport | None`: greatest `effective_at`; on an exact tie, the one that comes last in the input.

**Tests to write first.** Service `svc-ucr-west`, measure referrals-acceptable.
1. A text report of 3 at `2026-10-23T07:15Z` builds; `is_closed` is false.
2. Value 0 → `is_closed` true. Value 0 with measure occupied-patients → false.
3. Value −1 → `ValidationFailed` with field `value`.
4. Naive `effective_at` → field `effective_at`.
5. `report_type=CONFIRMED` without `derived_from` → field `derived_from`; with `derived_from="r1"` it builds.
6. `latest_report([])` → `None`.
7. Reports at 07:15Z, 09:12Z and 08:00Z → the 09:12Z one.
8. Two reports with the same time → the second in the list.
9. Reports are frozen.
