**Goal.** Turn a raw text message from a service's phone into a structured reply, using only the fixed words the product allows. This task covers single-service capacity replies and booking replies.

**Read first.**
- `backend/src/diucs/domain/codes.py` (F07).
- `docs/spec/domain-rules.md`, section 2.1.
- `docs/spec/ui-screens.md`, artboards "Reporter", "Reporter2", "Booking": real message exchanges.

**Rules you need.**
- Normalise first: trim, collapse inner whitespace to one space, ignore case.
- `Y` or `YES` → confirm the recorded figure.
- A whole number 0 to 999 → a new figure; `0` means closed. Leading zeros are fine (`04` → 4). Anything else that looks numeric (`-1`, `3.5`, `1000`, `4.`) is unrecognised.
- `CONFIRMED` or `CONFIRM` → booking confirm. `DECLINE` or `DECLINED` → booking decline. Either may carry a booking reference of 3 to 8 digits before or after the word: `CONFIRMED 4821`, `4821 confirmed`.
- No STOP, START or HELP handling: those are unrecognised like any other text. Free text ("yes please", "four") is unrecognised.
- The parser only reads words; it does not know whether a prompt is open or what was asked. A lone `1` after a decline is still `Number(1)`; the caller decides it is a reason digit.
- Lettered multi-service replies (`A 4`, `Y A`) are added in D10; do not write tests that assert they are unrecognised.

**Build.** `backend/src/diucs/domain/rules/reply_parser.py`:
- Frozen dataclasses `Confirm(letter: str | None = None)`, `Number(value: int, letter: str | None = None)`, `BookingConfirm(reference: str | None)`, `BookingDecline(reference: str | None)`, `Unrecognised(text: str)`.
- `ParsedReply = Confirm | Number | BookingConfirm | BookingDecline | Unrecognised`.
- `parse_reply(text: str) -> tuple[ParsedReply, ...]` (one item for everything in this task). `Unrecognised.text` is the trimmed original text.

**Tests to write first** (parametrised table).
1. `"Y"`, `"y"`, `" yes "`, `"YES"` → `(Confirm(),)`.
2. `"4"` → `(Number(4),)`; `"0"` → `(Number(0),)`; `"04"` → `(Number(4),)`; `"999"` → `(Number(999),)`.
3. `"1000"`, `"-1"`, `"3.5"`, `"4."`, `"four"` → `Unrecognised`.
4. `"CONFIRMED"`, `"confirmed"`, `"Confirm"` → `(BookingConfirm(None),)`.
5. `"CONFIRMED 4821"`, `"4821 CONFIRMED"` → `(BookingConfirm("4821"),)`.
6. `"DECLINE"`, `"declined"` → `(BookingDecline(None),)`; `"DECLINE 4821"` → `(BookingDecline("4821"),)`.
7. `"STOP"`, `"HELP"`, `"START"`, `"yes please"`, `""`, `"   "` → `Unrecognised`.
8. `"Y 4"` → `Unrecognised` (two answers at once are not allowed for one service).
9. `"CONFIRMED 12"` (two digits) → `Unrecognised`.
