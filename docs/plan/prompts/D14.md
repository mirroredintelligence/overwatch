**Goal.** Capture the booking rules that sit around the state machine: reply-by and phone-prompt times, one open request per service, short booking references, and matching a text reply to the right booking.

**Read first.**
- `backend/src/diucs/domain/rules/booking_state.py` (D13).
- `backend/src/diucs/domain/codes.py` (F07): `BookingStatus`. `backend/src/diucs/domain/errors.py` (F01): `Conflict`.
- `docs/spec/domain-rules.md`, section 3.2. `docs/spec/ui-screens.md`, artboard "Booking".

**Rules you need.**
- Reply-by = request time + 10 minutes. At + 5 minutes with no answer the advisor is prompted to phone. At + 10 minutes the request expires. Silence is never acceptance. Example: requested 14:16 → phone prompt 14:21, expires 14:26.
- One open (requested) booking per service at a time. A second request is refused until the first is answered, expires or is cancelled.
- References are 4-digit numbers, random, retried on collision with open bookings [ASSUMED], for example "4821". Use 1000–9999 so there is no leading zero.
- Matching a text reply: with a reference, use the open booking with that reference; if none, there is no open booking. Without a reference: none open → no open booking; exactly one → that one; more than one (several services on one phone) → ask which reference, listing them in ascending order.

**Build.** `backend/src/diucs/domain/rules/booking_rules.py`:
- `BOOKING_REPLY_WINDOW = timedelta(minutes=10)`, `PHONE_PROMPT_AFTER = timedelta(minutes=5)`, `REFERENCE_ATTEMPTS = 50` (extra).
- `booking_reply_by(requested_at) -> datetime`; `phone_prompt_at(requested_at) -> datetime`.
- `can_request(open_statuses_for_service: Iterable[BookingStatus]) -> bool` (false if any is `requested`).
- `new_reference(rng: random.Random, taken: set[str]) -> str`, raising `Conflict` after `REFERENCE_ATTEMPTS` collisions.
- `OpenBookingRef(booking_id: str, reference: str, service_id: str)`; `AskWhichReference(references: tuple[str, ...])`; `NoOpenBooking()`.
- `match_reply(open: Sequence[OpenBookingRef], reference: str | None) -> OpenBookingRef | AskWhichReference | NoOpenBooking`.

**Tests to write first.**
1. Requested 2026-10-23T13:16Z → reply-by 13:26Z, phone prompt 13:21Z.
2. `can_request([])` true; `[CONFIRMED, DECLINED]` true; `[REQUESTED]` false.
3. `new_reference(random.Random(42), set())` is 4 digits, between "1000" and "9999", and the same seed gives the same value.
4. With `taken` holding the first value the seeded generator would produce, the result differs from it.
5. A `taken` set of all 9000 references → `Conflict`.
6. `match_reply([], None)` → `NoOpenBooking()`.
7. One open (4821, UCR West), no reference → that booking. With reference "4821" → it; with "9999" → `NoOpenBooking()`.
8. Two open (4821 UCR East, 3170 UCR West), no reference → `AskWhichReference(("3170", "4821"))`; with "3170" → that one.
