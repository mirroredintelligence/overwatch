**Goal.** Add a guard that finds anything that looks like patient data in a message, and a build-failing test that renders every template on every supported channel and proves none of them can carry patient data.

**Read first.**
- `backend/src/diucs/domain/messages/templates.py`, `catalogue.py` (D15, D16): the ids, fields and channels.
- `docs/spec/domain-rules.md` section 9 and section 10.

**Rules you need.**
- No text, email or push ever contains a patient name, a full postcode, an NHS number or free text. A reference, an age band, a need category and an urgency are allowed. A postcode district alone (for example "DT4") is allowed.
- Detect:
  - Full UK postcode: `[A-Z]{1,2}[0-9][A-Z0-9]? ?[0-9][A-Z]{2}` (case-insensitive, word-bounded). "DT4 8XX" and "dt48xx" match; "DT4" does not.
  - NHS-number-like: exactly 10 digits, contiguous or grouped 3-3-4 with single spaces or hyphens, not part of a longer digit run. Phone numbers such as "07700 900123" (11 digits) must not match. Booking references (4 digits) must not match.
  - Personal titles followed by a capitalised word: `\b(Mr|Mrs|Ms|Miss|Dr)\.? [A-Z][a-z]+`.
  - Forbidden field names in a template call: `name`, `patient_name`, `nhs_number`, `postcode`, `address`, `dob`, `date_of_birth`, `free_text`.

**Build.**
- `domain/messages/privacy_guard.py`: `find_patient_data(text: str) -> list[str]` returning each offending fragment; `FORBIDDEN_FIELDS: frozenset[str]`.
- `tests/unit/domain/messages/test_no_patient_data_in_templates.py`: a table `SAMPLE_FIELDS: dict[MessageId, dict]` with realistic non-patient sample values for every id; for every id and every channel the id supports, render and assert `find_patient_data(text + subject + html) == []`.
- Also assert, for every id, that calling `render` with any one of `FORBIDDEN_FIELDS` added raises `ValidationFailed` (relies on D15's extra-field check).
- A completeness test: every `MessageId` member has an entry in `SAMPLE_FIELDS`, so adding a template without a sample fails the build.

**Tests to write first.**
1. `find_patient_data("Patient at DT4 8XX")` → `["DT4 8XX"]`.
2. `find_patient_data("Area DT4 only")` → `[]`.
3. `find_patient_data("NHS 943 476 5919")` → one match; `"9434765919"` → one match; `"943-476-5919"` → one match.
4. `find_patient_data("Call 07700 900123")` → `[]`; `"REQUEST 4821"` → `[]`.
5. `find_patient_data("Seen by Mrs Smith")` → `["Mrs Smith"]`.
6. The template sweep passes for all ids and channels.
7. Rendering B1 with `postcode="DT4 8XX"` raises `ValidationFailed`.

**Done when.**
- [ ] All tests pass; ruff, mypy, lint-imports clean.
- [ ] Deleting a `SAMPLE_FIELDS` entry makes the completeness test fail (check by hand, then restore).
