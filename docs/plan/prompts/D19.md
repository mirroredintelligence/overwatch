**Goal.** Normalise UK postcodes typed by an advisor and extract the postcode district used by service criteria.

**Read first.**
- `backend/src/diucs/domain/errors.py`: error base classes.
- `docs/spec/domain-rules.md` section 4.1 (districts) and `docs/spec/ui-screens.md` artboard "MapWeb" (postcode not found, choose the district).

**Rules you need.**
- A full postcode is outward code + space + inward code: `^[A-Z]{1,2}[0-9][A-Z0-9]? [0-9][A-Z]{2}$`. Normalise by trimming, upper-casing, removing all spaces, then inserting one space before the last three characters.
- Return `None` for anything that is not a full postcode, including partial ones such as "DT4 8X". The advisor then chooses a district instead.
- The district is the outward code: "DT4 8XX" → "DT4"; "SW1A 1AA" → "SW1A".
- A district typed alone ("dt4", " DT4 ") normalises to "DT4" if it matches `^[A-Z]{1,2}[0-9][A-Z0-9]?$`.
- The domain never sends a patient postcode anywhere; this module is pure string handling.

**Build.** `domain/rules/postcode.py`:
- `normalise_postcode(text: str) -> str | None`
- `postcode_district(postcode: str) -> str` (raises `ValidationFailed` if the input is not a normalised full postcode)
- `normalise_district(text: str) -> str | None`

**Tests to write first.** (parametrised)
1. `"dt48xx"` → `"DT4 8XX"`; `" DT4  8XX "` → `"DT4 8XX"`; `"sw1a1aa"` → `"SW1A 1AA"`; `"M11AE"` → `"M1 1AE"`.
2. `"DT4 8X"`, `"DT4"`, `""`, `"12345"`, `"DT4 8XXX"` → `None`.
3. `postcode_district("DT4 8XX") == "DT4"`; `postcode_district("SW1A 1AA") == "SW1A"`.
4. `postcode_district("dt48xx")` raises `ValidationFailed`.
5. `normalise_district("dt4") == "DT4"`; `normalise_district("DT4 8XX") is None`; `normalise_district("D") is None`.
