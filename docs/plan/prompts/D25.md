**Goal.** Define the domain events the core raises and how each maps to a Service Bus topic, so the outbox can carry them without patient data.

**Read first.**
- `backend/src/diucs/domain/codes.py` (F07): `Status`, `ReportSource`, `BookingStatus`, `AlertKind`.
- `docs/spec/architecture.md` section "Service Bus topics and queues"; `docs/spec/observability.md` "Domain events".

**Rules you need.**
- Events: `CapacityReported(service_id, report_id, value, source, at)`, `StatusChanged(service_id, before, after, at)`, `BookingRequested(booking_id, service_id, reference, at)`, `BookingResponded(booking_id, service_id, status, at)`, `BookingExpired(booking_id, service_id, at)`, `RegistrationSubmitted(registration_id, at)`, `RegistrationApproved(registration_id, service_id, at)`, `CriteriaApproved(criteria_id, service_id, version, at)`, `AlertRaised(alert_id, kind, service_id, at)`, `AlertAcknowledged(alert_id, by, at)`. `before` may be `None`.
- Topics: CapacityReported, StatusChanged → `capacity.events`; the three Booking events → `booking.events`; Registration events → `registration.events`; CriteriaApproved → `criteria.events`; Alert events → `alerts.events`.
- Session id (per-service ordering) for `capacity.events` is the service id; other topics have none.
- Events carry ids, counts and codes only. No patient values.

**Build.** `domain/events.py`:
- Frozen dataclasses above, each with `event_type: ClassVar[str]` equal to the class name and `to_payload() -> dict` returning JSON-safe values (datetimes as ISO 8601 strings ending in `Z`, enums as their values, `None` kept).
- `DomainEvent` = union of the classes; `topic_for(event) -> str`; `session_id_for(event) -> str | None`; `from_payload(event_type: str, payload: dict) -> DomainEvent` (round trip).

**Tests to write first.**
1. `CapacityReported("svc-ucr-west", "obs-1", 4, ReportSource.TEXT, 2026-10-23 10:12 UTC).to_payload()` equals `{"service_id": "svc-ucr-west", "report_id": "obs-1", "value": 4, "source": "text", "at": "2026-10-23T10:12:00Z"}`.
2. `topic_for` for one event of each family; `session_id_for(StatusChanged(...)) == "svc-ucr-west"`; `session_id_for(BookingRequested(...)) is None`.
3. Round trip `from_payload(e.event_type, e.to_payload()) == e` for every event class (parametrised).
4. `StatusChanged(before=None, ...)` round-trips.
5. No event class has a field named `postcode`, `name`, `nhs_number` or `needs` (introspect with `dataclasses.fields`).
6. `from_payload("Unknown", {})` raises `ValidationFailed`.
