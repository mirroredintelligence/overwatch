**Goal.** Generate and check the secrets people use without logging in: single-use link tokens, wall-screen pairing codes and support codes. Pure functions with injected randomness.

**Read first.**
- `backend/src/diucs/domain/errors.py`.
- `docs/spec/domain-rules.md` section 7 (link tokens, pairing code, support code).

**Rules you need.**
- Link token: at least 128 bits of randomness, URL-safe, single use, tied to one prompt (and one phone where known), expiring with the prompt. Only an HMAC-SHA256 hash of the token is stored, keyed with a server secret.
- Checking a link: `used` if `used_at` is set (takes precedence), else `expired` if `now >= expires_at`, else `ok`.
- Wall-screen pairing code: 6 digits, shown as "482 913", valid for 10 minutes.
- Support code: 8 characters from the unambiguous alphabet `ABCDEFGHJKMNPQRSTUVWXYZ23456789` (no 0, O, 1, I, L), shown as `XXXX-XXXX`, for example `K7R4-92QX`.

**Build.** `domain/rules/tokens.py`:
- `new_link_token(rng: Callable[[int], bytes] = secrets.token_bytes) -> str` (16 bytes, base64url without padding → 22 characters)
- `hash_token(token: str, secret: bytes) -> str` (hex)
- `LinkTokenRecord` as in contracts.md; `LinkCheck` StrEnum (`ok`, `expired`, `used`); `check_link(record, now) -> LinkCheck`
- `PAIRING_CODE_VALID_FOR = timedelta(minutes=10)`; `new_pairing_code(rng: Callable[[int], int] = secrets.randbelow) -> str`; `format_pairing_code(code) -> str`; `pairing_code_expired(issued_at, now) -> bool`
- `SUPPORT_CODE_ALPHABET`; `new_support_code(rng: Callable[[int], int] = secrets.randbelow) -> str`

**Tests to write first.**
1. `new_link_token(lambda n: bytes(range(n)))` is deterministic, 22 characters, only `[A-Za-z0-9_-]`; two calls with `secrets.token_bytes` differ.
2. `hash_token("abc", b"k")` equals the HMAC-SHA256 hex computed in the test with `hmac`; a different secret gives a different hash.
3. `check_link`: future expiry, unused → ok; `now == expires_at` → expired; used and expired → used.
4. `new_pairing_code(lambda n: 7)` → `"777777"`; codes keep leading zeros (rng returning 0 → `"000000"`); `format_pairing_code("482913") == "482 913"`.
5. Pairing issued 14:00: not expired 14:09:59; expired 14:10:00.
6. `new_support_code` with a fixed rng gives `XXXX-XXXX` using only the alphabet; 1000 random codes never contain `0 O 1 I L`.
