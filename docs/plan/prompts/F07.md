**Goal.** Define every local FHIR code system once, as Python enums, so the whole code base uses the same codes, system URLs and display words.

**Read first.**
- `backend/src/diucs/domain/errors.py` (F01).
- `docs/spec/contracts.md`, "`diucs/domain/codes.py` (F07)": the full list of enums and their values. Use those names and values exactly.
- `docs/spec/fhir-data-model.md`, "Code systems": which code system each enum is.

**Rules you need.**
- `BASE_URL = "https://diucs.example/"` (a placeholder; it must stay in one constant because identifiers cannot change once minted).
- `code_system_url(name)` returns `f"{BASE_URL}CodeSystem/{name}"`.
- Enum classes are `StrEnum`; the value is the FHIR code. Member names are upper snake case of the value (`Status.NOT_ACCEPTING = "not-accepting"`). For `AgeBand` use `A0_15 = "0-15"`, `A16_64 = "16-64"`, `A65_79 = "65-79"`, `A80_PLUS = "80+"`.
- Code system names: Status → `status`; Measure → `capacity-measure`; ReportSource → `report-source`; ReportType → `report-type`; ServiceCategory → `service-category`; NeedCategory → `need-category`; Urgency → `urgency`; AgeBand → `age-band`; AcuityMethod → `acuity-method`; BookingStatus → `booking-business-status`; DeclineReason → `decline-reason`; WithdrawReason → `withdraw-reason`; NotReachedReason → `not-reached-reason`; CancelReason → `cancel-reason`; RegistrationStatus → `registration-status`; CriteriaStatus → `criteria-status`; Channel → `channel`; AlertKind → `alert-kind`; Cadence → `report-cadence`; Role → `role`; ScopeFlag → `scope-flag`; ReportFlagReason → `report-flag-reason`; Outcome → `case-outcome`; BestFitNotUsedReason → `best-fit-not-used`; ReferrerType → `referrer-type`.
- Display words shown to people, for example Status: Accepting, Limited, Not accepting, Over capacity, Not updated, Out of hours. Urgency: Within 2 hrs, Today, Planned. NeedCategory: Fall, no injury; Frailty; Wound care; IV therapy; Palliative; Dementia; Suspected fracture; Head injury on anticoagulants; Infection isolation. Others: sentence case of the code with hyphens as spaces, unless you set an explicit word.

**Build.** `backend/src/diucs/domain/codes.py` with: all enums; `BASE_URL`; `code_system_url(name: str) -> str`; `Coding(system: str, code: str, display: str)` frozen dataclass; `CODE_SYSTEM_NAMES: Mapping[type[StrEnum], str]`; `display(member: StrEnum) -> str`; `coding_for(member: StrEnum) -> Coding`; `parse_code(enum_cls, code: str)` raising `ValidationFailed("code", ...)` for unknown codes.
