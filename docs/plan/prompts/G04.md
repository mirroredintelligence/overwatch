**The product.** DIUCS capacity helps an NHS urgent-care single point of access (SPOA) in Dorset. Community services, wards and virtual wards report how many referrals or beds they can take, by text message, a one-tap link, or an installed web app. Call advisors see a live wall board and a filtered list of services that fit a patient's needs, then ask a service to take the patient by text and wait for CONFIRMED. Shift leads chase late reports, register services and keep criteria current. Nothing anywhere holds a patient name or NHS number.

**The architecture.** Hexagonal. A Python back end (package `diucs` in `backend/src/diucs`) with four layers: `domain` (pure rules, no I/O), `application` (use cases and ports defined as `typing.Protocol`), `adapters` (inbound: FHIR REST, SMS webhook, link pages, workers; outbound: Neo4j, Redis, Azure Service Bus, SMS, email, push; `adapters/testing`: fakes for external providers only) and `bootstrap` (settings and the composition root). Dependencies point inwards only. A Next.js front end in `frontend/` talks only to its own `/api/bff/*` route handlers, which call the back end's FHIR R4B API. Neo4j is the only database, Redis is a cache, Azure Service Bus carries messages and scheduled work.

**Goal.** Finish the mapper: repeating or multi-part backbone elements become child nodes, and local extensions become `ext_` properties through an extension registry. After this task the HealthcareService and Location from the registration flow round-trip exactly.

**Rules you need.**
- R4 A backbone element that repeats or has several parts → child node labelled `<Type>_<Element>` (`HealthcareService_AvailableTime`, `HealthcareService_NotAvailable`, `HealthcareService_Eligibility`, `Location_HoursOfOperation`, `Organization_Contact`) linked from the parent with the catalogue name where one exists (`HAS_AVAILABLE_TIME`, `HAS_NOT_AVAILABLE`, `HAS_ELIGIBILITY`, `HAS_HOURS`, `HAS_CONTACT`), otherwise `HAS_ELEMENT`, with `order` and `fhirPath`. Child key `"<parentKey>#<element>[<order>]"`. Address and ContactPoint become `Address` and `ContactPoint` children via `HAS_ADDRESS` and `HAS_TELECOM`.
- R8 Extension → property `ext_<shortName>` from a registry mapping the URL to a short name and value type. URLs are `f"{BASE_URL}StructureDefinition/<shortName>"`. An unregistered URL raises `UnknownExtension(url)`. Later tasks register more extensions; keep registration a one-line call (`register_extension(ExtensionDef(...))`).
- Extensions registered now: `smsShortName`, `establishedCapacity`, `canExceedEstablished`, `usualRangeMin`, `usualRangeMax`, `reportCadence`, `limitedLevelPercent` (HealthcareService); `geocodeSource`, `geocodedAt`, `uprn` (Location); `reportType` (Observation: `number` or `confirmed`); `referrerType` (ServiceRequest).
- Location `position` → `positionLatitude`, `positionLongitude`. The Neo4j `position` point is set by G05, not here.

- Extend `to_graph` / `from_graph`. Afterwards `UnsupportedElement` only fires for genuinely unknown shapes.
