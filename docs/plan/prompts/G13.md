**Goal.** Produce RDF triples (Turtle) from the same mapper fragments used for the graph, in the "query projection" form described in the data model, so the graph can later be reasoned over or exchanged. Keep it to an exporter with tests.

**Read first.**
- `adapters/outbound/graph_store/mapper.py` and `extensions.py` (G02–G04): `GraphFragment`, `NodeSpec`, `RelSpec`.
- `docs/spec/fhir-data-model.md`: "RDF triples" (all subsections), "Identifiers, namespaces and code systems", and the ontology terms block.

**Rules you need.**
- Prefixes: `fhir: http://hl7.org/fhir/`, `res: https://diucs.example/fhir/`, `diucs: https://diucs.example/def#`, `cs: https://diucs.example/CodeSystem/`, `skos:`, `xsd:`, `prov: http://www.w3.org/ns/prov#`, `dcterms:`, `rdf:`, `rdfs:`, `owl:`. Build `res` and `cs` from `BASE_URL`; the domain is a placeholder until the real one is chosen.
- Resource node → `res:Type/id a fhir:Type`. Primitive property → `fhir:Type.element` with a typed literal (`xsd:dateTime`, `xsd:date`, `xsd:time`, `xsd:integer`, `xsd:boolean`, `xsd:decimal`, plain string otherwise). Reference relationship → `fhir:Type.element res:Target/id`. Concept relationship → `fhir:Type.element cs:<system-name>#<code>`, and each concept `a skos:Concept ; skos:inScheme cs:<system-name> ; skos:notation "code" ; skos:prefLabel "display"@en`. Backbone child → blank node linked with `fhir:Type.element`. Extension `ext_x` → `diucs:x`.
- Classes: a capacity Observation also gets `a diucs:CapacityReport`; Basic ServiceCriteria `diucs:ServiceCriteria`; booking Task `diucs:BookingRequest`; registration Task `diucs:Registration`; ServiceRequest `diucs:Case`. `CURRENT_CRITERIA` → `diucs:currentCriteria`, `ACCEPTS_NEED` → `diucs:acceptsNeed`, `EXCLUDES_NEED` → `diucs:excludesNeed`, `SUPERSEDES` → `diucs:supersedes`.
- A relationship property such as `APPROVED_BY {role, at}` → `prov:qualifiedAssociation [ a prov:Association ; prov:agent X ; prov:hadRole diucs:<Role> ; prov:atTime "..."^^xsd:dateTime ]`.
- Skip the `json`, `iri` and `*Code` helper properties.
- Not validated against the FHIR ShEx schemas. Say so in the module docstring; do not claim conformance.

**Build.** `adapters/outbound/graph_store/rdf_export.py`: `fragment_to_graph(fragment) -> rdflib.Graph`, `to_turtle(fragments: Iterable[GraphFragment]) -> str`, `ontology_turtle() -> str` (the ontology block from the data model). Add `rdflib` as a dependency.
