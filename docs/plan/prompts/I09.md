**Goal.** Implement `EmailSender` over SMTP so services that report by email get a plain, accessible message with one link, sent from a no-reply address to their role inbox. SMTP is an external provider: test it with an in-process SMTP server, no Neo4j needed.

**Rules you need.**
- From `DIUCS Capacity <capacity@diucs.example>` (configurable). Header `Auto-Submitted: auto-generated`. Footer line from the screens: "The link works once, needs no login, and expires at 10:30. This email has no patient information. Replies to this address are not read." (the template supplies the time).
- `multipart/alternative`, text part first, HTML second. If the template gives no HTML, build it from the text: escape, wrap paragraphs, turn the one link into a button-styled `<a>` with the template's visible label ("Confirm or update", "Review request"). Inline styles only; no images, tracking pixels or external fonts.
- Recipients are role inboxes. Never log the address or the body; log the message id and the SMTP `Message-ID`.
- `SendReceipt.provider_message_id` is the `Message-ID` you generate (`<uuid@diucs.example>`).
- SMTP 4xx → `TransientSendError`; 5xx recipient refused → `accepted=False`.
- `aiosmtplib`; settings `smtp_host`, `smtp_port`, `smtp_user`, `smtp_password`, `smtp_starttls`, `email_from`.
- **Open decision:** SMTP relay versus a transactional provider. The port hides it; add no provider-specific headers.

**Build.** `backend/src/diucs/adapters/outbound/email_smtp/smtp_email.py`: `SmtpEmail(settings)` implementing `EmailSender`; pure `build_message(to, subject, text, html, from_addr, message_id) -> EmailMessage`; `text_to_html(text, link_label) -> str`.
