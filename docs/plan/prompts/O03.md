**Goal.** Build the friction rules engine: a pure TypeScript module that watches interaction timing and emits one `ui.friction` event per rule firing, with the element id. It never looks at content and never ranks a person.

**Read first.**
- `frontend/lib/telemetry/events.ts` (O02): `track` and the event shape.
- `docs/spec/observability.md`, "Friction signals" and "Rolling friction into a score".

**Rules you need.** Thresholds are starting values [ASSUMED]; put them all in one exported `FRICTION_THRESHOLDS` object.
- Rage click: 3 or more clicks on the same element, or within 30 px of each other, inside 1 second.
- Dead click: a click on something that looks interactive with no navigation, DOM change, network call or state change within 1 second.
- Error click: a click followed within 2 seconds by an error message, an HTTP 4xx or 5xx, or a script error.
- Impatient click: a second click on the same control while its first request is still in flight.
- U-turn: route A, then B, then A again inside 5 seconds with no interaction on B.
- Thrash: 3 or more switches between the same two routes inside 10 seconds.
- Validation loop: the same field fails validation 3 or more times.
- Form abandonment: a field was focused and the person left without submitting; record the last field's element id.
- Hesitation: no interaction for 20 seconds on a quick-action screen (route templates listed in `QUICK_ACTION_ROUTES`: `/l/[token]`, `/respond/[serviceId]`, `/booking/[ref]`).
- Missed tap: a tap within 24 px of a control that did not land on it.
- Scroll thrash: 4 or more reversals of scroll direction inside 3 seconds.
- Stream gap: the live stream is down for more than 10 seconds while the page is open.
- Output: `ui.friction` with `kind`, `element.id`, `count`, `window_ms`.

**Build.** `frontend/lib/telemetry/friction.ts`: `createFrictionEngine({ now, emit })` returning methods `onClick({elementId, x, y, interactive})`, `onClickResult(elementId, result)`, `onRequestStart(elementId)`, `onRequestEnd(elementId, status)`, `onError(elementId?)`, `onRoute(template)`, `onValidation(elementId, valid)`, `onFocus(elementId)`, `onSubmit()`, `onLeave()`, `onInteraction()`, `onScroll(direction)`, `onStream(state)`, `tick()`. Pure: time comes from `now()`, no DOM access. A thin `attachFriction()` wires it to the DOM and to `track`, and is not unit-tested beyond a smoke test.

**Tests to write first.** Vitest with fake timers; one `describe` per rule.
1. Three clicks on the same element in 900 ms → one `rage` event, count 3. Three clicks 1.2 s apart → none.
2. Three clicks 20 px apart on different elements in 1 s → `rage`.
3. Click with result `none` after 1 s on an interactive element → `dead`.
4. Click then HTTP 500 at 1.5 s → `error-click`; at 2.5 s → none.
5. Second click during an open request → `impatient`.
6. `/case/[ref]` → `/case/[ref]/options` → back in 4 s with no interaction → `u-turn`.
7. Field fails validation 3 times → `validation-loop`.
8. 21 s idle on `/l/[token]` → `hesitation`; on `/case/[ref]` → none.
9. Four scroll reversals in 2.5 s → `scroll-thrash`.
10. Stream down 11 s → `stream-gap`.
