**Goal.** Define the ports for link tokens, secrets and phone hashing, plus the `LinkTokenService` that issues and burns single-use tokens. Tokens are stored in Neo4j; the secret and hasher are pure code with a fixed-secret fake.

**Read first.**

- `backend/src/diucs/application/ports/outbound/clock.py` (F06).
- `adapters/outbound/graph_store/driver.py`, `queries.py`, `migrations.py` (G01).
- `backend/tests/support/` (F10).

**Rules you need.**
- Only token hashes are stored; the token itself never is. Hash with HMAC-SHA256 keyed by the secret `link-token`.
- A token is single use. Burning an already-used token raises `Conflict`. The atomic `mark_used` must be safe under concurrent callers: `MATCH (t:LinkToken {tokenHash: $h}) WHERE t.usedAt IS NULL SET t.usedAt = $at RETURN count(t) AS n`; the method returns `n == 1`.
- Phone numbers are never stored in plain text outside the protected contact store (P16). Everywhere else use `PhoneHasher.hash(number)`: an HMAC keyed by the secret `phone-hash`, over the number normalised to digits with a leading `0`, so "+44 7700 900123" and "07700 900123" hash the same.
- Graph: `(:LinkToken {id, tokenHash, phoneHash, purpose, aboutId, expiresAt, usedAt})`, unique on `tokenHash`. No token text.

**Build.**
- `application/ports/outbound/tokens.py`: `LinkTokenRepository(Protocol)` (async: `add(record)`, `get_by_hash(token_hash)`, `mark_used(token_hash, at) -> bool`); `SecretStore(Protocol)`: `get(name) -> bytes`; concrete `LinkTokenService(repo, secrets, clock)` with `async issue(purpose, about_id, phone_hash, expires_at) -> str`, `async resolve(token) -> LinkTokenRecord | None`, `async burn(token) -> None`.
- `application/ports/outbound/identity.py`: `PhoneHasher(Protocol)`; concrete `HmacPhoneHasher(secrets)`; `normalise_uk_mobile(number) -> str`.
- `adapters/outbound/graph_store/link_token_repository.py`: `Neo4jLinkTokenRepository(tx)`; queries `Q-LINK-ADD`, `Q-LINK-GET`, `Q-LINK-MARK-USED`.
- `adapters/testing/fixed_secrets.py`: `FixedSecretStore(dict[str, bytes])`.

**Tests to write first.**
1. `issue` returns a 23-letter token (DEC-154; it was 22 characters); the stored node's `tokenHash` equals `hash_token(token, secret)` and the token text is not in the graph (search every node property).
2. `resolve(token)` returns the record; `resolve("unknown")` → `None`.
3. `burn` then `resolve` shows `usedAt` set; a second `burn` raises `Conflict`.
4. Integration: two concurrent `mark_used` calls on the same hash: exactly one returns True.
5. Unit: `HmacPhoneHasher.hash("+44 7700 900123") == hash("07700 900123")`; a different secret gives a different hash.
6. Unit: no registered `Q-LINK-*` query has a `token` parameter (only `tokenHash`).
