**Goal.** Define the ports for geocoding, postcode centroids, travel time, terminology (ODS lookups) and FHIR validation, with fixed-table fakes. These are external providers, so fakes are correct here; the real adapters come later.

**Read first.**
- `backend/src/diucs/domain/rules/postcode.py` (D19): normalised postcodes and districts.
- `docs/spec/architecture.md`: flows F4 and F8, and the Geocoding and Routing rows of "Technology choices".
- `docs/spec/ui-screens.md`: artboard "MapWeb" (travel ranges).

**Rules you need.**
- Site addresses are geocoded once at registration. A patient postcode is resolved only from a local centroid file; it never leaves the Trust's hosting.
- Travel time is a range, not a promise, with its source (for example "35 to 50 min by road").
- The ODS check confirms an organisation code exists and is active.
- Validation returns issues; an empty list means valid.

**Build.**
- `application/ports/outbound/geo.py`: `LatLon(lat: float, lon: float)`; `AddressCandidate(uprn: str, line: str, town: str, postcode: str, position: LatLon)`; `TravelRange(low_minutes: int, high_minutes: int, source: str)` (validates `0 <= low <= high`); `Geocoder(Protocol)`: `find_addresses(postcode)`; `PostcodeLocator(Protocol)`: `centroid(postcode) -> LatLon | None`, `district_centroid(district) -> LatLon | None`; `TravelTime(Protocol)`: `estimate(origin, destination) -> TravelRange`.
- `application/ports/outbound/terminology.py`: `OdsRecord(code, name, active: bool, org_type: str, postcode: str | None)`; `ValidationIssue(severity, code, path, message)`; `Terminology(Protocol)`: `ods_lookup(code) -> OdsRecord | None`, `display(system, code) -> str | None`; `FhirValidator(Protocol)`: `validate(resource: dict, profile: str) -> list[ValidationIssue]`.
- `adapters/testing/fixed_geo.py`: `FixedGeocoder(table)`, `FixedPostcodeLocator(postcodes, districts)`, `FixedTravelTime(default: TravelRange, table: dict | None = None)`.
- `adapters/testing/fixed_terminology.py`: `FixedTerminology(ods, displays)`, `PassThroughValidator` (always `[]`), `RecordingValidator(issues)` (returns preset issues and records calls).

**Tests to write first.**
1. `FixedPostcodeLocator({"DT4 8XX": LatLon(50.61, -2.46)}, {"DT4": LatLon(50.62, -2.47)})`: `centroid("DT4 8XX")` found; unknown → `None`; `district_centroid("DT4")` found.
2. `FixedTravelTime(TravelRange(35, 50, "fixed"))` returns the default; a table entry keyed by (origin, destination) overrides it.
3. `TravelRange(50, 35, "x")` raises `ValidationFailed`.
4. `FixedTerminology` returns an active `OdsRecord` for a known code and `None` otherwise.
5. `PassThroughValidator().validate({...}, "x") == []`; `RecordingValidator` returns its preset issues.
