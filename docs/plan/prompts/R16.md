**The product.** DIUCS capacity helps an NHS urgent-care single point of access (SPOA) in Dorset. Community services, wards and virtual wards report how many referrals or beds they can take, by text message, a one-tap link, or an installed web app. Call advisors see a live wall board and a filtered list of services that fit a patient's needs, then ask a service to take the patient by text and wait for CONFIRMED. **The architecture.** Hexagonal. Dependencies point inwards only. A Next.js front end in `frontend/` talks only to its own `/api/bff/*` route handlers, which call the back end's FHIR R4B API. Neo4j is the only database, Redis is a cache, Azure Service Bus carries messages and scheduled work.

**Goal.** Give advisors a search over NHS Pathways disposition (Dx) codes, so the score picker can only record a code chosen from a list. The pilot uses a small sample file; the licensed list comes later.

**Rules you need.**
- Search text: trimmed, case-insensitive, at least 2 characters (fewer → 400 `invalid`, "Type at least 2 characters"). Match the code prefix or any part of the display text. At most 20 results, in code order.
- Roles `advisor` and `clinical` only; others → non-revealing 404.
- **Open decision: the real Dx list.** NHS Pathways codes come from NHS England under licence. Ship `backend/data/pathways_dx_sample.json` with about 10 clearly fake entries, such as `{ "code": "DxSAMPLE01", "display": "Sample disposition 1 (not a real code)" }`. The file's first entry says the codes are not real. Do not copy real Dx codes.
- The search reads through the `Terminology` port, so changing the source is a configuration change.

**Build.**
- Add `async def search_pathways_dx(self, text: str, limit: int = 20) -> list[tuple[str, str]]` to the `Terminology` Protocol and to `FixedTerminology`.
- `backend/src/diucs/adapters/outbound/terminology/pathways_dx_file.py`: `PathwaysDxFile(path)`, loaded once. If `local_terminology.py` (I12) exists, add the method there and reuse its loader.
- `backend/src/diucs/adapters/inbound/fhir_rest/routes_terminology.py`: `GET /terminology/pathways-dx?q=<text>` → 200 `[{ "code", "display" }]`.
- Wire the file adapter in the container from setting `pathways_dx_file`.
