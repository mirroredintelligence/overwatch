**Goal.** Lock down the browser: a strict content security policy with a per-request nonce, no third-party scripts or fonts, and the standard security headers on every response.

**Read first.**
- `frontend/next.config.ts`, `frontend/middleware.ts` if it exists, and `frontend/app/layout.tsx` (F03, F09).
- `docs/spec/architecture.md`, "Security, IG and operations" (Browser row).

**Rules you need.**
- No third-party scripts and no third-party requests. Load Atkinson Hyperlegible with `next/font/google`, which self-hosts the files at build time, so nothing is fetched from Google at runtime. Remove any `<link>` to fonts.googleapis.com.
- CSP, built per request with a fresh nonce: `default-src 'self'; script-src 'self' 'nonce-<n>' 'strict-dynamic'; style-src 'self' 'nonce-<n>'; img-src 'self' data:; font-src 'self'; connect-src 'self'; worker-src 'self'; manifest-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'; object-src 'none'; upgrade-insecure-requests`. In development only, allow `'unsafe-eval'` in `script-src` for the dev server.
- Other headers: `Strict-Transport-Security: max-age=63072000; includeSubDomains`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()`, `Cross-Origin-Opener-Policy: same-origin`.
- Pass the nonce to Next.js through the `x-nonce` request header so its inline scripts get it.
- Cookies are HTTP-only and same-site; that is set by the session code (W02), not here, but check it is so and say if not.

**Build.** `frontend/lib/security/csp.ts` with `buildCsp(nonce: string, dev: boolean): string` and `securityHeaders(): Record<string, string>`; `frontend/middleware.ts` that creates the nonce, sets the CSP and other headers on the response and `x-nonce` on the request, keeping any existing middleware logic (merge, don't replace). Update `app/layout.tsx` to use `next/font/google`.

**Tests to write first.**
1. `buildCsp("abc", false)` contains `script-src 'self' 'nonce-abc' 'strict-dynamic'` and `frame-ancestors 'none'`, and does not contain `unsafe-eval` or `unsafe-inline`.
2. `buildCsp("abc", true)` contains `'unsafe-eval'`.
3. The middleware sets a different nonce on two requests.
4. `securityHeaders()` includes each header above with the exact value.
5. Playwright (`e2e/security.spec.ts`): load `/screen`; every network request goes to the same origin; the response has the CSP header; no console CSP violations.
