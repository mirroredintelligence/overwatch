**Goal.** Build `HandleInboundText` for capacity replies: take a text from a reporter's phone, parse it, apply the reply policy, and record a figure, a confirmation, or the right refusal. Unknown numbers get no reply.

**Read first.**

**Rules you need.**
- Grammar: `Y`/`YES` confirm; 0–999 new figure; `A 4` lettered figure; `Y A` lettered confirm; plain `Y` on a grouped prompt confirms all. Booking words → outcome `booking-not-handled`, nothing sent (U22 adds them).
- Open prompt: the latest C1, C2, C5, C8 or C9 to this phone; reply-by `sent_at + 30 min`.
- `PromptState` from the latest report, trailing confirmations, the latest accepted report (time, value) and `pending_out_of_range` from cache key `recheck:{phone_hash}:{service_id}` (TTL until reply-by).
- Decisions: `RecordNumber` → `ReportCapacity` (source text, performer = reporter's role, `replaced_value` if correction, `flag` passed through); `RecordConfirm` → `ConfirmCapacity`, and `ConfirmLimitReached` → C6; `RejectLate` → C5 ("Too late: the 12:30 cut-off had passed, so 5 was not used. New question: …"); `AskRecheck` → set the cache key, send C7; `Unrecognised` → C11.
- Grouped prompt: rebuild letters with `letters_for` over services with a C9 from that send; record each separately; suppress per-service C3 and send one C10 ("Thanks. B) UCR East updated to 2. A) UCR West still needs a reply: Y A, or A and a number.").
- Unknown phone hash: no write, no message, outcome `dropped`.
- **A Y on a stale figure is not recorded as current (hazard H-31).** D11 `decide_capacity_reply` never looks at the figure's date, so this use case must. When the figure a Y would confirm is older than its window, do not call `ConfirmCapacity`: ask the reporter for a new number (C2 wording), or keep the old figure with its own date, but never stamp it as current. Decided in DEC-148: the age test is D05's `STALE_WARNING_AFTER` (2 hours), measured at the moment the prompt was sent, exactly 2 hours still inside; the reporter gets the new message C12 (the figure is out of date; send a number), outcome `stale-figure`.

**Build.** `application/use_cases/handle_inbound_text.py`: `HandleInboundTextCommand(idempotency_key /*provider message id*/, from_phone_hash, text, received_at)`; `HandleInboundTextResult(outcome: str, service_ids: tuple[str, ...])` with outcomes recorded, confirmed, late, confirm-limit, recheck, help, dropped, booking-not-handled; `HandleInboundText(uow_factory, clock, ids, idempotency, cache, report_capacity, confirm_capacity)`. Refusals are a `Communication` plus `SendMessage` outbox message, audited `use_case="HandleInboundText"`.
