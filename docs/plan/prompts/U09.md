**Goal.** Build the board projector: when capacity or booking events arrive, rebuild the board from Neo4j, store it in the cache, and publish a small "board changed" message so open pages refetch. Add a cached board reader.

**Read first.**
- `application/use_cases/query_board.py` (U08) and its integration test seeding.
- `ports/outbound/cache.py`, `adapters/testing/memory_cache.py` (P09). Redis is not a store of record, so the in-memory cache fake is allowed here.
- `domain/events.py` (D25); `docs/spec/architecture.md` platform rows "Read-model cache" and "Live updates to open pages".

**Rules you need.**
- Cache key `board:v1`, TTL 60 s backstop [ASSUMED]. Rebuild on `StatusChanged`, `CapacityReported`, `BookingRequested`, `BookingResponded`, `BookingExpired`, `CriteriaApproved`, `PhoneTaskRaised`; ignore others.
- Channel `board.updates`; message `{"type": "board-changed", "service_id": <id or null>, "at": <iso>}`, no figures. A missed message is harmless.
- Rebuilding is idempotent. If the cache fails, `get_board` falls back to `QueryBoard` and does not raise.

**Build.** `application/use_cases/board_projector.py`: `board_to_dict(board) -> dict`, `board_from_dict(data) -> Board` (ISO 8601, enum values as strings); `BoardProjector(query_board, cache, clock)` with `async handle(event_type, payload) -> bool` and `async get_board(actor) -> Board`; system actor `Actor(role=Role.WALL, practitioner_id=None, device_id=None, channel="system", service_ids=frozenset())`.

**Tests to write first.** `tests/integration/application/test_board_projector.py`: real Neo4j for the board data (seeded as in U08), `InMemoryCache` for the cache.
1. `handle("CapacityReported", {"service_id": "ucr-west", ...})` stores `board:v1` and publishes one `board.updates` message with `service_id` "ucr-west" and no figures.
2. `handle("SomethingElse", {})` → False, nothing stored or published.
3. `board_from_dict(board_to_dict(b)) == b` for a board with every status (pure; can live in `tests/unit`).
4. `get_board` with an empty cache computes from Neo4j, stores and returns; a second call within 60 s reads the cache (count queries with a wrapper around `QueryBoard`).
5. Write a new report through `ReportCapacity`, call `handle("CapacityReported", …)`, then `get_board` → the cached board shows the new figure.
6. After 61 s the entry has expired and is recomputed. A cache whose `get` raises → `get_board` still returns the computed board.
