**Goal.** Build the two booking timer handlers the scheduled-work consumer calls: the 5-minute advisor phone prompt and the 10-minute expiry.

**Read first.**
- `application/use_cases/request_booking.py` (U17), `respond_to_booking.py` (U18).
- `application/work.py`, `graph_store/scheduled_work_repository.py` (P08).

- `application/actor.py` (P05); `docs/spec/domain-rules.md` 3.2; `docs/spec/ui-screens.md` "Booking" (No reply card).

**Rules you need.**
- +5 min: if still `requested`, outbox `booking.events` `BookingPhonePrompt` with booking id, service id and reference only. If answered, nothing.
- +10 min: if still `requested`, move to `expired` (Task.status `cancelled`, statusReason `expired`, businessStatus `expired`), release pending, emit `booking.events` `BookingExpired`. If final, nothing.
- At-least-once delivery: mark the `ScheduledWork` `done` on first run; a second delivery is a no-op. Work not `scheduled` is ignored. A late handler acts on current state.

**Build.** `application/use_cases/booking_timers.py`: `BookingPhonePromptCommand(work_id, booking_id)`, `ExpireBookingCommand(work_id, booking_id)`; `BookingPhonePrompt(uow_factory, clock)`, `ExpireBooking(uow_factory, clock)` returning `TimerResult(acted: bool)`. Append `BookingPhonePrompt(booking_id, service_id, reference, at)` to `domain/events.py`. Register both in the consumer's handler map. Audit `use_case="ExpireBooking"` with the system actor; if `application/actor.py` has no `SYSTEM_ACTOR`, add `Actor(role=Role.AUDIT, practitioner_id=None, device_id=None, channel="system", service_ids=frozenset())`.

6. After expiry a new `RequestBooking` for the service succeeds.
7. A consumer dispatch test routes `booking-expire` work to `ExpireBooking`.
