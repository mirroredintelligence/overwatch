**Rules you need.**
- Both only from `confirmed`. Withdraw → `withdrawn` (Task.status `cancelled`, statusReason `withdrawn`). Not reached → `not-reached` (Task.status `failed`).
- Withdraw reasons: `now-full`, `staffing`, `cannot-reach-patient`, `other`. Not-reached: `not-at-address`, `no-answer`, `gone-to-hospital`, `other`. Required.
- Actor: reporter for the service or a link-token holder for the booking.
- After withdrawal the slot no longer counts against effective available.
- Withdrawal: outbox `booking.events` `BookingWithdrawn`; `schedule_work(kind=WorkKind.ESCALATE_TO_LEAD, about_id=booking_id, due_at=+10 min)`. `AcknowledgeWithdrawal` (advisor acts) cancels it. `EscalateWithdrawal`, if still unacknowledged, emits `alerts.events` `WithdrawalEscalated`.
- Not reached: `booking.events` `BookingNotReached`; no timer [ASSUMED].
