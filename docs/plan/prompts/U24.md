**Rules you need.**
- Only for scope entries flagged `in-pilot`; otherwise `NotAllowed` with the message "Only services in the pilot can be invited".
- Invitation = Task with code `invite-reporter`: focus the service, requester the lead's role, owner the invitee practitioner, `restriction.period` 48 hours. Also create the registration record in state `invited`.
- The mobile number goes into `ContactStore`; the rest of the graph keeps only `PhoneHasher.hash(number)`. Normalise UK mobiles to `+447…` before hashing; reject anything that is not a UK mobile (`07` + 9 digits, spaces allowed) with `ValidationFailed("mobile", "Enter a UK mobile number, like 07700 900123")`.
- Invitation link token: purpose `invite`, about the invitation id, phone hash set, expires now + 48 h. Link `https://diucs.example/i/<token>`.
- Text I1: "DIUCS: You are invited to report capacity for UCR West. Set up takes about 3 minutes: <link> Valid for 48 hrs."
- Suggested channel (`text`, `email`, `push`) and role label are stored; the person can change channel during set-up.
- Resend burns the old token, issues a new one with a fresh 48 hours and sends I1 again. Only while the registration is `invited`.

**Build.** `backend/src/diucs/application/use_cases/invite_reporter.py`: `InviteReporterCommand(idempotency_key, actor, service_id, role_label: str, mobile: str, suggested_channel: Channel)` → `InviteReporterResult(invitation_id, registration_id, expires_at)`; `InviteReporter(uow_factory, idempotency, link_tokens, phone_hasher, clock, ids)`. `ResendInvitationCommand(idempotency_key, actor, invitation_id)` and `ResendInvitation`. Add `ReporterInvited(invitation_id, service_id, at)` to `domain/events.py` (append only). Outbox: I1 on `messages.outbound` and `registration.events/ReporterInvited`.
